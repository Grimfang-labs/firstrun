# Security

FirstRun is currently a planning repository with no supported software release.

The planned runner executes package installation and documentation examples. A virtual environment is not a security sandbox. Run only trusted projects locally. Use disposable CI runners without secrets for reviewed project code; never run untrusted fork code in a privileged workflow.

Do not post credentials, exploit details affecting others, or private source code in public issues. Use GitHub's private vulnerability reporting for this repository when enabled. If unavailable, contact an organization owner through a private channel listed on their public profile; request a reporting channel before sharing sensitive details.

No response-time or remediation guarantee is claimed during planning.
